# Little Wars (working title)

A turn-based grid-tactics campaign for the browser, after H. G. Wells's
*Little Wars* (1913). Two armies of toy soldiers, Red and Blue, fight across
a "Country" built on a floor from books, bricks, boards and chalk. The
campaign is a tutorial and ten battles in three acts and a finale, about
10-15 minutes each, with a short ink story between them.

It is the second example game for Knotwork, an ink + browser game kit,
after Amontillado.

## Status

Design only. There is no game code yet. See GDD.md.

## Source

The rules are adapted from H. G. Wells, *Little Wars* (1913), which is in
the public domain in the United States. This game restates and changes
those rules for a grid; it does not include Wells's text. The original can
be read at Project Gutenberg (eBook #3691).
